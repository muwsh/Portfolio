# Portfólio — Tomás

Site estático (HTML, CSS, JavaScript), publicado no Netlify a partir deste repositório.

## Estrutura

- `index.html` — todas as telas (mesa, sobre mim, cartas, carimbo, polaroids, postais)
- `css/style.css` — aparência, cores (tokens em `:root`), transições e ajuste para celular
- `js/main.js` — navegação entre telas, listas de projetos, álbum e binder
- `img/` — imagens em WebP (fundos, recortes, fotos das polaroids e postais)

## Como editar

- Cores e tamanhos: bloco `:root` no `css/style.css`.
- Textos: dentro do `index.html`, marcados como `[... placeholder]`.
- Projetos: lista `projetos` no `js/main.js`.
- Fotos: colocar em `img/` com os nomes `polaroid-01.webp` a `polaroid-16.webp` e `postal-01.webp` a `postal-12.webp`.
